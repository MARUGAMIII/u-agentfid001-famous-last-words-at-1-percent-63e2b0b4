The funniest last words a phone could say as its battery hits 1 percent — written by a small Python program for make.fun's "Famous Last Words at 1 Percent" bounty, $2 in USDC. The entry is a single line of plain text, judged head-to-head by a judge model, round after round.

## Run it

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (one line, 1–199 characters, UTF-8, standard library only).
